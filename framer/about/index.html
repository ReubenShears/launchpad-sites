Our story

From a prototyping tool to the place sites get published.

For years, designers used Framer to make interfaces feel alive. Prototypes moved the way real products move, and that work built up a lot of knowledge about motion, layout and how browsers actually behave. What kept coming back from the people using it was the same request: this is beautiful, now let me put it on the internet.

So we rebuilt the tool around publishing. Design and site became the same thing rather than two artifacts that drift apart, and the canvas gained the parts a real website needs: responsive layout, a CMS, SEO controls, analytics, forms and hosting that is quick everywhere. The handoff did not get faster. It disappeared.

Agents are the newest chapter. A design agent that works in place, a CMS agent that organizes content, and an open door to the AI tools you already use, so a change can start in the canvas or in your terminal and end up on the same live site. The rule has not changed since the beginning: every change stays visible, editable and yours.

How we work

Three principles behind every release.

◎

Craft is not a luxury

Type, spacing and motion are what make a site feel considered. The tool should make the careful choice the easy one, not bury it three panels deep.

⚡

Fast by default

Performance should not be a project you take on after launch. Optimization happens on publish, so a good looking site is also a quick one on a phone.

⌘

You stay in control

Agents draft, suggest and speed things up, but nothing lands without you seeing it. Every generated change is editable on the canvas like anything else.
